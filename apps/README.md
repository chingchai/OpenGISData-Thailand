# แอปที่เกี่ยวข้อง

โปรเจกต์หลักเผยแพร่ข้อมูล GIS ที่ราก repository ส่วนแอปแต่ละระบบเก็บโค้ด คู่มือ และสคริปต์เฉพาะไว้ด้วยกัน

| แอป | เริ่มต้น | คู่มือติดตั้ง |
| --- | --- | --- |
| TPMAP Dashboard | [README](tpmap-dashboard/README.md) | [Quick Start](tpmap-dashboard/QUICK-START-SUBDIRECTORY.md) |
| ระบบจัดซื้อจัดจ้าง | [README](procurement-system/README.md) | [Deployment](procurement-system/DEPLOYMENT.md) |

เลือกคู่มือทั้งหมดจาก [สารบัญ deployment](../docs/deployment/README.md) ถ้าติดตั้งจากโครงสร้างเดิมให้อ่าน [การย้าย path](../docs/deployment/MIGRATION.md) ก่อนอัปเดต

คำสั่งในคู่มือแต่ละฉบับอาจเริ่มจาก checkout root หรือ app directory ให้ตรวจ `cd` ก่อนรัน สคริปต์ติดตั้งบางตัวสร้างฐานข้อมูลใหม่และเปลี่ยนการตั้งค่าเซิร์ฟเวอร์ ควรเลือกเฉพาะกรณีติดตั้งที่ตรงกับระบบของตน
